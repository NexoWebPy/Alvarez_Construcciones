Landing page corporativa, moderna y totalmente responsiva diseñada para **AC Alvarez Construcciones**, empresa paraguaya especializada en el diseño y edificación de **Casas Alpinas (A-Frame)** de alta calidad.

---

## 🚀 Características Principales

* **Diseño Responsivo (Mobile-First):** Layout adaptado dinámicamente para dispositivos móviles, tablets y monitores de alta resolución.
* **Integración Comercial Directa:** Flujo de contacto automatizado mediante la API de WhatsApp para solicitudes formales de asesoría y cotización.
* **Optimización de Medios:** Gestión de imágenes y componentes estructurales optimizados para máxima velocidad de carga.
* **Arquitectura Limpia:** Estructuración modular de código HTML5 semántico, CSS3 Flexbox/Grid y JavaScript ES6+.
* **Protocolos SEO Avanzados:** Metadatos enriquecidos, soporte para indexación mediante `sitemap.xml` y `robots.txt`.
* **Open Graph Protocol (OG):** Configuración de tarjetas predeterminadas con vista previa de imagen y metadatos para plataformas de mensajería (WhatsApp, Telegram, redes sociales).
